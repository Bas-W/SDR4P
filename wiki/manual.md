# Manual [WIP]
## Usage
### Signal source
To start using SDR4P, a signal source must be set.  
First select your SDR module / signal source from the "source" menu.  
To start capturing data, click the "start" button in the top bar.

### VFO
By default the "radio" VFO is active.
The selected demodulator can be changed in the "radio" menu.
Tune the VFO to your desired frequency and make sure the audio output is enabled.

## Controls [WIP]
### Main
#### VFO
##### Tuned frequency
The frequency which the active vfo is tuned to can be changed in various ways:
- Clicking / dragging the FFT or waterfall plot
- Scrolling the mouse wheel when the cursor is in the FFT or waterfall plot
  - SHIFT-key: big steps
  - ALT-key: small steps
- Clicking / scrolling the frequency indicator at the top of the window
- Clicking a bookmark (on plot or in bookmark list)
#### Waterfall / FFT plot
##### Scale
The maximum displayed bandwidth of the plot is determined by the captured bandwidth. 
The plot can be scaled to view a smaller, more detailed portion of the spectrum.
The scale can be changed in the following ways:
- Using the slider on the right side of the plot
- Scrolling the mouse wheel when the cursor is in the plot while holding the CTRL-key
